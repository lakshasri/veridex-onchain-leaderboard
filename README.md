# Veridex

Veridex is a blockchain-based judging system for coding contests that ensures transparency, fairness, and immutability.

Traditional contest platforms rely on centralized evaluation, making results vulnerable to manipulation, disputes, and lack of auditability. Veridex solves this by moving the judging process on-chain.

## Key Features

- Organizer-controlled participant and judge registration
- Strict judge-to-participant assignment enforcement
- Multi-criteria scoring (problem solving, code quality, efficiency)
- Weighted score aggregation on-chain
- Immutable submissions (no edits once submitted)
- Finalization lock — results cannot be changed after completion
- Fully transparent leaderboard with verifiable scoring history

## Tech Stack

- Solidity (Smart Contracts)
- Remix IDE
- Ganache (Local Blockchain)
- MetaMask (Wallet Integration)
- Frontend (React / Ethers.js)

## Use Cases

- University hackathons
- Coding competitions
- Scholarship evaluations
- Merit-based selection systems

## Goal

To eliminate bias and create a fully auditable judging system where every score is transparent, verifiable, and permanently recorded.
